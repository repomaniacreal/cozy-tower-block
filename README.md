# 🎪 Cozy Tower Bloxx: Festival Edition

A charming, cozy, and relaxing tower-stacking web game built with pure **HTML5 Canvas**, **CSS3**, and **Vanilla JavaScript**, featuring a procedural **Web Audio API** Lo-Fi & Kalimba soundtrack.

Inspired by classic physics-based building games, this **Festival Edition** introduces vibrant animated backgrounds (Ferris wheel, hot air balloons, flying sky lanterns, and celebratory fireworks) combined with boutique pastel apartment blocks, combo multipliers, and an optional Zen Mode.

---

## ✨ Key Features

- **🎨 Vibrant Festival Visuals**:
  - Parallax scrolling background featuring a rotating Ferris wheel, drifting hot air balloons, birds, clouds, and flying lanterns.
  - Dynamic sky themes that transition automatically (or manually via toggle): *Morning Carnival*, *Sunset Lanterns*, and *Night Festival*.
- **🏡 Boutique Apartment Blocks**:
  - 6 distinct pastel color themes (Coral Fiesta, Sunny Mango, Mint Patisserie, Berry Pop, Lavender Dream, Tangerine Zing).
  - Detailed window styling, balconies, awnings, flower pots, and festive triangular bunting flags.
  - **Golden Penthouse Crown**: Appears every 5 floors, rewarding extra points and triggering celebration fireworks.
- **🎵 Procedural Lo-Fi & Kalimba Audio**:
  - Built entirely using the Web Audio API (no external MP3 files required).
  - Generates warm Major 7th chord progressions and soothing Kalimba plucks upon block landings.
- **🕹️ Smooth Gameplay & Controls**:
  - Swing crane mechanics with adjustable momentum.
  - Juice effects including combo multipliers (`🔥 COMBO`), floating score callouts (`PERFECT!`, `SUPER PERFECT!`), shockwave rings, and screen shake.
  - **Zen Mode**: Toggle off life loss for a completely stress-free, endless stacking experience.
- **📱 Fully Responsive**: Optimized for both desktop (click/spacebar) and mobile touchscreens.

---

## 🚀 Getting Started

No installation, bundlers, or package managers are required! 

1. Download or copy the complete code into a single file named `index.html`.
2. Double-click the file to open it directly in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).

---

## 🎮 How to Play

1. **Tap or Click** anywhere on the screen (or press **Spacebar**) to release the swinging block from the crane.
2. **Stack Accurately**: Land the block as close to the center of the tower as possible to keep your platform width intact.
3. **Build Combos**: Landing consecutive perfect drops increases your **COMBO multiplier** and triggers bonus points.
4. **Avoid Misses**: If a block misses the tower completely or overhangs too much, you lose a life (unless **Zen Mode** is active).

---

## 🎛️ Controls & UI Buttons

- **Click / Tap / Spacebar**: Drop the active block.
- **✨ Zen Mode**: Toggle unlimited lives on/off for stress-free play.
- **🔄 Sky Theme Cycle**: Switch between Auto, Morning, Sunset, and Night modes.
- **🔊 Sound Toggle**: Enable or mute the procedural background music and sound effects.

---

## 🛠️ Built With

- **HTML5 Canvas**: For high-performance 2D rendering and animations.
- **CSS3**: For glassmorphism UI styling, gradients, and responsive layout.
- **Vanilla JavaScript (ES6+)**: For game loop physics, block slicing mechanics, particle systems, and event handling.
- **Web Audio API**: For real-time procedural music generation and sound effects.
